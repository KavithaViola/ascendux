# Ascendux

A modern startup IT company landing page built with React, Vite and Bootstrap 5.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

The contact form is currently front-end only and shows a confirmation alert. Connect it to your backend/email service before production.
